# 🐈‍⬛ Neon Cat 404

> **Too lazy to do it manually. Too crazy to leave it alone.**

Hi, I'm **Neon Cat 404**.

I'm a young guy with an unreasonable number of ideas and an extremely reasonable amount of energy to actually execute them.

So naturally...

**I write code to do the work for me.** 💀

---

## 💤 About Me

I'm probably one of the laziest people you'll meet.

Not the *"I don't want to do anything"* kind of lazy.

More like:

> *"Why would I spend 10 minutes doing this when I can spend 6 hours building something that does it automatically forever?"*

That's basically my entire development philosophy.

I like building things, breaking things, fixing things, starting random projects at completely inappropriate hours, and occasionally wondering how I ended up with another repository.

My brain has two modes:

**1. `I'll do it tomorrow.`**
**2. `WAIT... I HAVE AN IDEA.`**

There is no third mode.
